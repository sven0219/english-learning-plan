# Day 1 — Weekly Status Update

## 1. Daily Passage

> Good morning. Here is a quick update on our task. We have completed the initial planning and prepared a simple test. We are currently reviewing the test results, and everything is on track. We found one small issue, but it does not affect the main function. The main blocker is that we still need approval for the next step. If we receive the approval today, we can continue tomorrow morning. The next step is to complete the review and share the result with the project team. We expect to finish this work by Friday. I will send another update if there is any change to the schedule. Please let me know if you have any questions.

## 2. Key Meeting Phrases

- `Here is a quick update on ...` — 下面快速汇报一下……
- `We are currently working on ...` — 我们目前正在进行……
- `The main blocker is ...` — 当前主要阻碍是……
- `The next step is ...` — 下一步是……
- `We expect to finish ... by ...` — 我们预计在……之前完成……

## 3. Replace and Practice

- `the initial planning` → `the first test` / `the document review`
- `approval` → `more information` / `a test result`
- `tomorrow morning` → `this afternoon` / `next Monday`
- `by Friday` → `by the end of the day` / `next week`

## 4. Questions

1. What has the team completed?
2. What is the main blocker?
3. What is the next step?
4. When does the speaker expect to finish?

## 5. Retelling Challenge

不看原文，用一分钟说明：已经完成什么、当前在做什么、主要阻碍和下一步。
