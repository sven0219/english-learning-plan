# Day 7 — Test Scope and Timeline

## 1. Daily Passage

> We are reviewing a small database change for the test environment. The basic test has passed, but one performance check is not complete. The current ETA, or estimated time of arrival, for the test result is Wednesday afternoon. In this meeting, ETA means the expected completion time, not travel time. The release date is still TBC, or to be confirmed, after we see that result. I understand the request to release on Wednesday morning, but I am afraid that timeline is not realistic. Could we reduce the first release to the most important change? This would lower the testing risk and keep the schedule clear. If the team agrees, I will update the test plan today. Let us confirm the scope now and make the final release decision on Wednesday.

## 2. Key Meeting and Business Phrases

- `The current ETA for ... is ...` — ……目前的预计完成时间是……（适合会议、邮件和即时消息；应说明ETA具体指什么。）
- `I understand the request, but ...` — 我理解这个请求，但是……（会议中礼貌提出不同意见。）
- `I am afraid that timeline is not realistic.` — 恐怕这个时间安排不太现实。（语气礼貌，但应继续说明原因或替代方案。）
- `Could we reduce the first release to ...?` — 我们可以把第一批发布缩小到……吗？（适合会议中协商范围。）
- `Let us confirm the scope now.` — 让我们现在确认范围。（用于会议中推动决定，语气直接但中性。）

## 3. Abbreviations in Context

| Abbreviation | Full form | 中文含义 | Usage note |
|---|---|---|---|
| ETA | Estimated time of arrival | 预计到达或完成时间 | 口语、邮件和即时消息中常见；IT语境常指预计完成时间或下次更新时间，需要说明。 |
| TBC | To be confirmed | 待确认 | 常见于计划、邮件和状态表；表示已有初步安排，但仍需最终确认。 |

## 4. Replace and Practice

- `a small database change` → `an API update` / `a configuration change`
- `one performance check` → `one security review` / `one rollback test`
- `Wednesday afternoon` → `Thursday morning` / `Friday afternoon`
- `reduce the first release` → `move the target date` / `add one more reviewer`

## 5. Questions

1. Which test has already passed?
2. What does ETA mean in this meeting?
3. Why does the speaker disagree with a Wednesday morning release?
4. When will the team make the final decision?

## 6. Retelling Challenge

不看原文，用一分钟讨论一个虚构变更的测试范围和时间线，说明ETA、TBC、风险和你的替代建议。
